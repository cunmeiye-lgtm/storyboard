# 纹身贴分镜与视频提示词 Skills

上传一张纹身贴款式展示图，让支持技能和 AI 图片生成的 Agent 生成独立分镜参考图、图片编号映射和可复制的完整中文视频提示词。

典型请求：

> 这个款式按模板生成，15秒、3:4、自然写实，不露脸、无口播、无字幕。

## 两个技能怎么选

| 技能 | 适用款式 | 显色逻辑 |
|---|---|---|
| `tattoo-video-storyboard` | 彩色即显色款；也支持明确指定的草本机制 | 默认揭纸后已有完整颜色 |
| `herbal-tattoo-storyboard` | 草本渐显色款 | 刚揭纸近乎透明，时间跳切后展示完成显色的结果 |

草本的显色时间、持久性和耐水性只使用用户确认的本款或系列资料，不从图片推断，也不把其他商品的性能当作本款承诺。

```text
使用 $skill-installer，从 https://github.com/cunmeiye-lgtm/storyboard 安装两个技能：
skills/tattoo-video-storyboard
skills/herbal-tattoo-storyboard
```

也可以分别提供技能目录链接：

- [彩色 / 通用纹身贴技能](https://github.com/cunmeiye-lgtm/storyboard/tree/main/skills/tattoo-video-storyboard)
- [草本渐显色纹身贴技能](https://github.com/cunmeiye-lgtm/storyboard/tree/main/skills/herbal-tattoo-storyboard)

安装后在下一轮对话使用；如果仍未发现技能，重新打开会话或重启客户端后再试。若同名技能已经存在，先检查现有版本，不要强行覆盖自行修改的文件。

### 手动安装 / 其他 Agent

通过本仓库的 **Code → Download ZIP** 下载并解压，将需要的完整技能文件夹放到目标 Agent 支持的技能目录，再按该客户端要求重新加载。

不要只复制 `SKILL.md`：`agents/` 和 `references/` 也要保留。其他平台的安装路径和调用语法以其自身说明为准；不保证所有 Agent 都支持 Codex 的 `$技能名` 调用方式。

## 使用示例

上传展示图后发送：

```text
使用 $tattoo-video-storyboard，按模板生成这个彩色纹身贴款式。
```

```text
使用 $herbal-tattoo-storyboard，按模板生成这个草本纹身贴款式。
本款一般1–2天完成显色。
```

```text
使用 $tattoo-video-storyboard，这个款式做10秒、3:4、快闪漫画风，
生成独立分镜图和完整中文视频提示词。
```

用户指定的时长、风格、画幅和产品资料覆盖默认值。只需要文字时明确说“只输出分镜设计与提示词，不生成图片”。

## 默认效果与交付

- 15秒、3:4、自然写实摄影，6张独立分镜图。
- 成年人身体局部，不露脸、无口播、无旁白、无字幕、不提价格。
- 包含实际将纸片放到皮肤上的动作、湿压和揭纸；纸片为略大于完整图案的纯白正方形。
- 彩色款：成品开场 → 白纸定位 → 湿压 → 揭纸显色 → 日常展示 → 微距收尾。
- 草本款：显色成品开场 → 放纸 → 湿压 → 揭纸透明初态 → 时间跳切后显色 → 微距收尾。

每次在当前项目 `output/` 下新建独立款式目录，已有目录使用版本号保留。交付包括原图副本（文件可读时）、最终分镜图、分镜与图片映射表、逐镜图片提示词、完整中文视频提示词。

默认参考映射为 `@image1` 对应商品原图、`@image2` 至 `@image7` 对应六张真实分镜图。没有生成图片时只映射实际素材，不虚构后续图片编号。

## 能力和使用边界

- 技能提供工作流与模板，不附带图片模型、视频模型、API Key 或额度。实际出图需要接收方 Agent 已有可用的 AI 图片生成工具；无法出图时只能交付文字并说明缺项。
- 默认不创建真实视频任务。生成视频需要用户另行明确要求，并遵循所在项目的工具和费用约定。
- 图案、字形、贴用部位和人体结构需要逐镜目视检查；AI 不保证像素级复刻。无法修正的差异应明确说明。
- 不提供未经确认的防水、持久或健康承诺；AI 画面不是实际产品测试证据。
- 发布版本不包含商品图片、生成素材、任务响应、凭据或本机业务代码。

## 文件结构

每个技能均包含 `SKILL.md`、`agents/openai.yaml` 和 `references/prompt-templates.md`。两个技能可以单独安装；两者同时存在时，明确的草本请求优先使用草本专用技能。
